# Treeways Release Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Treeways read as a maintained project, not a launch prototype — green CI on `main`, a web manifest branded "Treeways" with real installable icons, and a tagged `v1.0.0` release.

**Architecture:** Four independent, sequentially-gated tasks. Task 1 establishes a green baseline (local verification + confirm CI triggers on `main`). Tasks 2–3 are TDD: a vitest regression test on `public/manifest.webmanifest` is written first, then the manifest and icon assets are changed to pass it. Icons are authored as one SVG and rasterized to PNGs with the already-installed Playwright — no new dependency. Task 4 moves the changelog entry into a `1.0.0` section, tags `v1.0.0`, and publishes a GitHub Release, gated on a green CI run on `main`.

**Tech Stack:** Vite 6, vanilla JS, npm (CI uses `npm ci`), Node 20 (`.nvmrc`), Vitest + jsdom for unit tests, Playwright for e2e and icon rasterization. GitHub Actions + `gh` CLI for CI/release.

## Global Constraints

- **Package manager: npm.** CI runs `npm ci` against `package-lock.json`. Use `npm` for every install/run command. Do not introduce bun.
- **Node version: 20** (per `.nvmrc`). Run all commands under a Node 20 shell (`nvm use 20` if needed).
- **No new dependencies.** Icons are rasterized with `playwright` (already a devDependency). Do not add `sharp`, `pwa-asset-generator`, or any other package.
- **Scope of "branding": the web app manifest only** — `public/manifest.webmanifest`. Do **not** touch the service-worker cache names `urban-canopy-shell-v2` / `urban-canopy-data-v2` in `public/sw.js`; they are asserted by `tests/e2e/offline.spec.js` and renaming them breaks the offline e2e job. Do **not** touch `public/cities/vancouver/manifest.json` (the city *data* manifest — different concern, no "Urban Canopy Engine" string). Do **not** touch `package-lock.json`'s `"name": "urban-canopy-engine"` or `AGENTS.md`'s title in this plan — out of scope.
- **Brand marks:** app name is "Treeways". Manifest `theme_color`/`background_color` stay `#f8f6ef` (warm paper, already in `index.html`). Canopy green token from `DESIGN.md` is `oklch(0.56 0.12 145)`; use the hex approximation `#3a7a48` in SVG/PNG for renderer compatibility. Wordmark is already Georgia serif in `src/styles/base.css`.
- **Version:** `package.json` is already `"version": "1.0.0"`. No `v1.0.0` git tag exists (only `pre-build-week-2026-07-13`). This release creates `v1.0.0`.
- **Commit style:** `type: description` — `feat`, `fix`, `chore`, `docs`, `refactor`, `test`.
- **CI gating:** GitHub Actions is enabled and the `CI` workflow is active on `push` and `pull_request`. Every push to `main` must produce a run; if a push does not, investigate via the Actions tab before continuing. Do not tag the release until `gh run list --branch main --limit 1` shows `conclusion: success`.

## File Structure

- **Modify** `public/manifest.webmanifest` — replace `name`/`short_name` and fill the empty `icons` array. One responsibility: the installable PWA manifest.
- **Create** `public/icon.svg` — the single source mark (512×512 viewBox, maskable-safe). One responsibility: the brand glyph.
- **Create** `public/icon-192.png`, `public/icon-512.png`, `public/apple-touch-icon.png` — rasterized outputs committed to the repo so installs work without a build step.
- **Create** `scripts/generate-icons.mjs` — Playwright-based rasterizer. One responsibility: render `public/icon.svg` to the three PNG sizes. Kept in `scripts/` to match the existing `scripts/city/*` generator pattern and allow regeneration.
- **Modify** `index.html` — add `<link rel="icon">` and `<link rel="apple-touch-icon">` in `<head>`.
- **Create** `tests/manifest.test.js` — Vitest regression test that loads the manifest JSON and asserts brand + icons. One responsibility: stop the manifest from regressing.
- **Modify** `CHANGELOG.md` — promote "Unreleased" into a dated `## 1.0.0` section.
- **Build outputs** (`dist/manifest.webmanifest`, `dist/icon*.png`) are regenerated by `npm run build`; never edit them directly.

- [ ] **Step 4: Write the Playwright rasterizer**

Create `scripts/generate-icons.mjs`:

```javascript
// Render public/icon.svg to the PNG sizes Treeways ships.
// Run: node scripts/generate-icons.mjs  (requires `npx playwright install chromium` once)
import { chromium } from 'playwright';
import { readFile, writeFile } from 'node:fs/promises';
import { resolve, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';

const root = resolve(dirname(fileURLToPath(import.meta.url)), '..');
const svg = await readFile(resolve(root, 'public/icon.svg'), 'utf8');

const targets = [
  ['icon-192.png', 192, 192],
  ['icon-512.png', 512, 512],
  ['apple-touch-icon.png', 180, 180],
];

const browser = await chromium.launch();
try {
  for (const [name, w, h] of targets) {
    const page = await browser.newPage({ viewport: { width: w, height: h } });
    const sized = svg.replace('<svg', `<svg width="${w}" height="${h}"`);
    await page.setContent(
      `<!doctype html><meta charset="utf-8"><body style="margin:0">${sized}</body>`,
      { waitUntil: 'load' },
    );
    const el = await page.$('svg');
    const png = await el.screenshot({ omitBackground: false });
    await writeFile(resolve(root, 'public', name), png);
    await page.close();
    console.log(`wrote public/${name} (${w}x${h})`);
  }
} finally {
  await browser.close();
}
```
